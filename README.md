# 毛毛任务 · 汪汪队学习桌 🐶

一个为 1 年级小朋友（人教版上下册）打造的 **手机端 PWA 学习桌**，
采用汪汪队·毛毛的暖色卡通主题：奶油底 + 红蓝主色 + 圆角卡片，
完美对应你提供的风格参考图。

## 核心功能一览

| 模块 | 内容 |
|---|---|
| **首页** | 天气卡 + 问候语 + 连续打卡天数、骨头罐子可视化余额、今日任务清单（打勾置灰）、坚持徽章 |
| **语文** | 拼音（20 道题 + 🔊 朗读）、识字（4 大主题共 30 字 + 点读发音）、看图说话（emoji 占位图 + 听示例 + 🎙️ 语音识别） |
| **数学** | 加法 / 减法 / 分解组合；可自由切换 **10 以内 / 20 以内**；每题 🔊 朗读题目 |
| **书法·控笔** | 家长可设 3-30 分钟定时器；含 5 个描红选项（横/竖/斜/波/圆），完成后打勾置灰 |
| **习惯** | 唇肌训练、洗鼻子、刷牙；每项奖励骨头不同 |
| **愿望清单** | 自定义添加、设置骨头消耗、兑换（兑换与删除需家长模式） |
| **奖励** | 骨头商店：**🍖 喂食**（狗粮/骨头饼干/鸡肉/蛋糕） + **👕 打扮**（消防帽/警察帽/领结/披风/星星徽章） |
| **设置** | 家长模式开关、修改密码、教材切换（上下册下拉框）、控笔默认时长、清空数据 |

## 设计亮点

- **暖奶油主题**：参考图风格还原，柔和护眼。
- **骨头罐子可视化**：首页右侧骨头罐子 + 数字，奖励多少一目了然。
- **连续打卡激励**：3/7/14/30/60/100 天共 6 个里程碑徽章，达到 7 天、30 天可解锁特殊装扮。
- **家长模式**：所有敏感操作（修改密码、教材切换、兑换/删除愿望、清空数据）需输入 4 位密码（默认 `0000`）。在顶部标题处 **长按 3 秒** 也能解锁。
- **语音朗读**：拼音 / 识字 / 题目 / 控笔提示 全部用浏览器内置 `speechSynthesis`（zh-CN），零成本。
- **看图说话**：自带 6 张 emoji 占位图（狗/苹果/一家人/消防车/下雨/生日），后续可在 `data.js` 替换为 `image url` 或 `file://`。
- **PWA**：manifest + service worker，可在 iPhone / Android 上"添加到主屏幕"全屏运行。
- **完全离线**：所有题库 / 状态都在 `localStorage`，断网也能玩。

## 在 iPhone 17 上"添加到主屏幕"

1. Safari 打开预览链接（预览地址见聊天窗口）。
2. 点底部分享按钮（方块 + 向上箭头）→ **添加到主屏幕**。
3. 名称可改为"毛毛任务"，点右上角"添加"。
4. 从主屏幕点击图标即可全屏运行，无浏览器地址栏，体验接近原生 App。

> 提示：iOS 第一次 TTS 朗读需要先点一下页面触发用户手势；之后即可正常朗读。

## 怎么继续扩展

- 替换看图说话图片：编辑 `js/data.js` 里的 `KANTU` 数组，把 `emoji` 字段替换为 `img: "images/xxx.jpg"`，并在 HTML 中渲染时改用 `<img>`。
- 添加新愿望：直接进入"愿望清单"页底部输入。
- 扩充题库：往 `data.js` 里的 `PINYIN` / `SHIZI` / 数学函数 `buildArith` 中追加即可。
- 切换教材：在"设置"→"教材切换"中下拉选择（上册/下册），目前题库通用，后续可在 `data.js` 拆分 `PINYIN.upper / PINYIN.lower`。
